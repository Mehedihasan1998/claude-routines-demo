# Project rules for this repo

- This is a teaching demo for the Learnio "Claude Routines" lesson.
- Keep every change small. Do exactly one BACKLOG.md item per run — nothing else.
- Never remove or break the localStorage save/load logic in index.html.
- Never delete or rewrite BACKLOG.md, except to check off the item you completed
  and add today's date next to it.
- Always work on a new branch and open a pull request. Never push straight to main.
- Write commit messages and PR descriptions in plain English. No jargon, one paragraph.
- If no unchecked item exists in BACKLOG.md, do nothing and end without committing.
