# Habit Tracker — Routines demo repo

This is the small demo repository for the "Claude Routines for Beginners" lesson.
It reuses the habit-tracker idea from the Claude Code lesson so the story continues,
but it's a self-contained starter — you don't need the original lesson's file.

## What's in here
- `index.html` — a single-file habit tracker (plain HTML/CSS/JS, saves to the browser's localStorage)
- `BACKLOG.md` — a short list of small, safe improvements. The routine built in this lesson
  reads this file, does the top item, checks it off, and opens a pull request.
- `CLAUDE.md` — house rules so any Claude Code session (live or a Routine) stays inside safe limits.

## Before recording
1. Create a new **public or private GitHub repository** (e.g. `habit-tracker-routines-demo`).
2. Push these three files to its default branch (`main`).
3. Connect that repo to your claude.ai account if you haven't already (Claude Code on the web
   will prompt you to install the Claude GitHub App the first time you pick a repo).
4. Leave `BACKLOG.md` with at least one unchecked item before every take, so the demo has
   something to do.
